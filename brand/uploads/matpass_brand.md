MATPASS

One-Page Brand Kit

⸻

🧭 Brand Positioning

MatPass is a compliance-first eligibility platform for wrestling programs. It eliminates uncertainty around athlete clearance by centralizing requirements, status, and documentation into one decisive dashboard.

Core Attributes:

* Authoritative
* Urgent
* Reliable
* No-nonsense

⸻

🎨 Color Palette

Primary Colors

* Warm Light Background — #E8E5DF
    Neutral canvas that contrasts with bold messaging
* Charcoal Black — #0F1215
    Primary text and dark sections; strong, high-contrast anchor

Accent Color (Signature)

* Mat Red — #D92D20
    Signals urgency, alerts, and critical status (use sparingly, intentionally)

Supporting Colors

* Slate Gray — #4B5563
    Secondary text
* Border Gray — #D1D5DB
    Dividers, outlines, subtle UI structure
* Inverted Light Text — #F5F5F5
    Text on dark sections

⸻

🔤 Typography

Headline Font

Anton (or Bebas Neue as alternative)

* Heavy, condensed, commanding
* Used for hero statements and section headers

Body & UI Font

Inter (Regular / Medium)

* Clear, neutral, highly legible for dense information

Pairing Guidance

* Headlines: Anton Bold, tight tracking
* Body: Inter Regular/Medium, generous line-height

⸻

🧱 Logo Usage

Primary Mark

* “MatPass” with Mat in Red and Pass in Black

Guidelines

* Maintain color split (do not swap colors)
* Prefer light background or high-contrast dark sections
* Keep clear space equal to the height of the “M” around the logo
* Avoid outlines, shadows, or gradients on the mark

⸻

🎯 UI & Button Styling

Primary CTA

* Background: Charcoal (#0F1215)
* Text: Inverted Light (#F5F5F5)

Secondary CTA

* Outline: Charcoal (#0F1215)
* Text: Charcoal (#0F1215)
* Background: Transparent / Light

Alert / Status

* Use Mat Red (#D92D20) for blockers, missing requirements, and critical flags

Interaction

* Hover (Primary): #1A1F24
* Hover (Secondary): light gray fill #F3F4F6
* Radius: 6–8px

⸻

📦 Component Style

* Sections alternate: Light background → Dark (Charcoal) blocks
* Strong typographic hierarchy; minimal decoration
* Dividers are thin, subtle, and frequent for scannability

⸻

📸 Visual Style

* Documentary feel: clipboards, mats, weigh-ins, paperwork
* High contrast, minimal color—red only for emphasis
* Cropped, close-in imagery to create urgency and focus

⸻

🗣 Tone & Voice

* Direct
* Urgent
* Problem-first, outcome-clear

Examples:

* “Know who’s cleared to wrestle.”
* “Don’t find out on match day.”
* “No clearance, no guesswork.”

⸻

⚠️ Do / Don’t

Do

* Lead with bold, decisive headlines
* Use red sparingly to highlight risk or action
* Keep layouts tight and information-forward

Don’t

* Overuse red (it loses meaning)
* Add playful elements—this is compliance, not social
* Bury critical status behind low-contrast UI

⸻

🚀 Brand Direction (Next Steps)

* Define status system (Cleared / Pending / Missing / Expired) with color + icon rules
* Create a compact icon set for requirements (physical, waiver, baseline, etc.)
* Establish dashboard design tokens for tables, badges, and alerts
